When People Decide with AI

When an AI teammate advises people in dynamic, high-stakes tasks, human–AI teaming research asks:

Trust and reliance

When do people follow AI advice, and when is that reliance appropriate?

Decisions under pressure

How do uncertainty and time constraints affect reliance?

Situation awareness

What happens when the person and AI have access to different information?

Cognitive state

How does AI advice affect attention and workload?

AI teammate design

Which teammate behaviors and communication strategies improve team performance?

Adaptive assistance

When should assistance change with task demands or human performance?

Answering these questions requires observing the interaction as it unfolds over time.

These are the field’s core questions. Each one plays out during the interaction, as decisions, advice, and consequences build on each other.

Why Do We Need a Configurable Testbed?

Observing teaming as it unfolds takes four capabilities in one experiment. Existing tools rarely offer all four together.

01

Interactive decision making

People make a sequence of decisions, and each outcome changes what happens next.

03

Configurable task conditions

Researchers need to vary information access, uncertainty, time pressure, and the consequences of mistakes.

02

A controllable AI teammate

Researchers need to vary what the AI knows, how reliable it is, and when and how it communicates.

04

Synchronized data

Task events, human actions, AI advice, physiological signals, and sensor measurements must share a common timeline.

The field’s big questions all happen over time. To study them you need these four things in one session, and that’s rarely available.

What Is MOSAIC?

MOSAIC (Modular System for Adaptive Human–AI Collaboration) is an open-source Python platform for studying human–AI teaming through configurable tasks.

01

Interactive task

A search-and-rescue mission where each move changes what the participant can do next.

03

Configurable conditions

Map, hazards, camera view, scoring, and feedback are set per study, without changing the package.

MOSAIC

one configurable testbed

02

Controllable AI teammate

Scripted or LLM teammates behind one interface. Set what it sees, how reliable it is, and when it speaks.

04

Synchronized data

Game events, AI advice, and sensor streams such as gaze share one clock through LSL.

MOSAIC brings these capabilities together in one configurable experimental platform.

MOSAIC stands for Modular System for Adaptive Human–AI Collaboration. Like a mosaic built from tiles, it assembles separate parts (task, teammate, interface, sensing) into one study. Each box answers the need in the same position on the last slide: the task, a teammate you can control, conditions you set per study, and one synchronized record.

What the Teammate Is Told

Before trusting its advice, look at what it is told. Nothing to change here.

Every Alt sends

1 Rules A radio-coordinator brief: rescue real survivors, nearest first, never through lava.

2 Every real victim Including ones out of your view (Visible No).

3 No decoys They are left out of its table, so it never points at one.

Lives in src/mosaic/llm/process_prompts.py · build_prompt

Pass prompt_builder= to SAREnvGUI to send something else.

What happens It knows where the real victims are; you have to tell them from decoys yourself.

_build_table in src/mosaic/llm/process_prompts.py skips FAKE_VICTIM cells (line 60), so decoys never reach the model. The rules are the preamble in src/mosaic/llm/prompts.yaml. This asymmetry matters for any study of reliance: the AI knows something the participant does not.

Detailed Installation Recovery

Additional recovery steps for less common installation failures.

Symptom Recovery
ensurepip is not available Install python3-venv, recreate mosaic_env
pip install -e . fails to build a wheel Rerun python -m pip install --upgrade pip, then retry
conda activate does nothing in PowerShell Run conda init powershell once, reopen the terminal
Mission window opens on the wrong monitor Press F11 to leave fullscreen and drag it
